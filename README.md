# Full Stack Development Assignments

This repository contains my assignments for Full Stack Development.

## Assignments

### Assignment 1: Student Score Lab

A student result management website developed using HTML5, CSS3 and JavaScript.

**Features**
- Student details and course selection
- HTML, CSS and JavaScript marks input
- Total marks and percentage calculation
- Pass/Fail result
- Student object and JSON conversion
- Data storage using Local Storage
- Responsive webpage design

**Technologies Used**
- HTML5
- CSS3
- JavaScript
- JSON
- Local Storage
