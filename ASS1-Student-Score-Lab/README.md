# Assignment 1 - Student Score Lab

## Description
Student Score Lab is a student result management website created using HTML, CSS and JavaScript.

## Features
- Enter student details and select a course.
- Enter HTML, CSS and JavaScript marks.
- Calculate total marks and percentage.
- Display Pass/Fail status.
- Convert student data into JSON.
- Store result data in Local Storage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON
- Local Storage

## How to Run
1. Download the assignment folder.
2. Open `index.html` in a web browser.
3. Enter the student details and marks.
4. Click **Calculate Result** to view the scorecard.
